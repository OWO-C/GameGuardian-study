MEMORY RANGES

Android 記憶體區域分佈地圖 (Ranges)

GameGuardian 提供精準的記憶體區段過濾機制。正確勾選區段能提速 10 倍並防止無效搜尋。

Anonymous (A) 推薦標的：金幣、血量、動態物件

Anonymous 區域是用戶端 C/C++ 動態分配 (malloc) 最常儲存遊戲核心數據的地方（如 Unity 的 Mono 堆疊、Unreal Engine 的動態物件數據）。90% 的數值修改都在此區段。

存取權限： Read / Write (rw-p)
搜尋速度衝擊： 中等 (推薦勾選)
常見範例： Unity Mono 遊戲數值, C++ Struct
AUTOMATION ENGINE

Lua 腳本自動化 開發工作坊

GameGuardian 內建高階 Lua 5.3 解譯器，可自動化複雜搜尋、製作彈出式選單與鎖定記憶體位址。

經典實用腳本範本庫 (11 大實戰情境)

script.lua
-- GameGuardian Lua Automation Script
核心 API：gg.searchNumber(text, type, encrypted, sign, memoryFrom, memoryTo)
實戰場景：適用於已知明確數字（金幣、鑽石、經驗值）的快速一鍵自動化修改。
專家技巧：在 editAll 之前可先呼叫 gg.getResults(count) 確認回傳陣列，避免過多雜訊位址。
